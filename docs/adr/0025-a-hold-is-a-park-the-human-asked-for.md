# A Hold is a park the human asked for

An operator typing "pause" into the session had no concept to land on. The agent relaying it could declare a Wait — bounded, expiring, chained until the budget refused it — or fall silent and be Nudged twice into a park whose notification reads as failure. A shipped Run showed the workaround in action: the agent declared a thirty-minute Wait "until they resume", knowing it would expire and need re-declaring, and that the budget would eventually refuse what the human had explicitly asked for. The glossary listing *pause* as an Avoid word under Wait was the tell — the concept was missing, not misnamed.

The missing concept is not a longer Wait. A Wait waits on something that comes back on its own — a background agent, a review check — which is why it carries a deadline and a budget: expiry is the re-check, and the budget is what stops a wait-looping agent stalling its Lane with no human told. A pause waits on a *person*, and nothing about a person comes back on a timer. The model already has a family for that: a Gate State and an Escalation both mean Naiad stops acting and the human types into the session directly. What was missing was the third member — the handover the human initiated — and it arrives as a fourth Protocol verb: `naiad hold "<why>"`. The Run parks deliberately: no Nudges, no expiry, no budget, revived exactly as any parked Run is, by the human typing and the agent signalling again.

The declarer is the agent, not the operator, and that was a real choice. An operator-side command would carry no trust problem at all — you cannot lie to yourself — but it would move the pause out of the session, and the whole point is that "pause" is typed into the TUI where the work is. Naiad reads no Claude Code internals (ADR 0002), so the agent is the only possible relay. The trust problem that relay reopens — an unbounded claim in the mouth of the party the Wait budget exists to distrust — is answered by visibility rather than a bound: declaring a Hold notifies the operator once, calm-worded, naming the reason. A confused agent declaring a Hold nobody asked for is thereby no worse than any parked Run, which is an accepted state; without the notification it would be precisely the silent indefinite stall the budget was built to prevent, which is why the notification is load-bearing and not a courtesy. The redundant ping in the honest case — being told what you just asked for — is the accepted cost.

A Hold ends when the agent next signals: an Announcement, a Question, or a fresh Wait supersedes it, which is the existing revival rail every parked Run already rides (ADR 0012) and adds no release verb to the Protocol. The accepted consequence is inherited from that rail: an agent sent back to work that ends a turn without signalling sits under the Hold unnudged, exactly as it would after a Gate State. The reason is required, refused empty in the same shape as a Wait's, because the notification and the Run log are read by an operator who must see what the Hold was for — and because the agent relaying the human's words is what later distinguishes an honest Hold from a confused one.

The agent learns the verb in three places: the Protocol preamble, where the other three verbs live; the Nudge wording, which today offers only announce-or-wait and so steered the shipped Run into its Wait workaround; and the Wait-budget-spent refusal, which an agent burning its budget on a human's pause hits at exactly the moment it needs to know Hold exists, and which today steers it wrong with "announce or ask".

## Consequences

The Protocol grows its fourth verb, surface every agent acts against, and the reason this is written down: reshaping it later means retraining every Prompt and skill that learned it. The parked family gains a fourth road in — Gate State, Escalation, silence past the Nudge bound, and now Hold — all resolving to the same Notify, so the decision core learns a signal but no new recovery shape.

A confused or lying agent can park its own Run indefinitely with one command. Accepted: the notification makes it visible immediately, the Lane it blocks is its own, and the old behaviour reached the same parked state anyway — later, noisier, and against the human's wishes when the pause was real.

A Hold suppresses the silence rule for as long as it stands, which makes it the one signal with no clock. The hang rule is untouched — a Hold is declared by ending a turn, and the hang rule watches sessions that never end one.
