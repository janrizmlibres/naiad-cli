# A declared Wait is not silence

Supersedes ADR 0006.

An agent that ends its turn without announcing is read as silent: Nudged at the silence bound, Nudged once more, then the Run is parked for a human. ADR 0006 accepted that reading because Naiad could not distinguish an agent deliberately waiting from one that forgot to announce — the signals were identical — and told Workflow authors to keep any waiting inside the turn, as a single blocking command.

A shipped Run broke that premise. The code-review skill launches background agents, and Claude Code's own harness tells the agent to end its turn — the session is re-invoked when tracked background work finishes. The agent ended its turn correctly by the harness's rules, a wake was already guaranteed, and Naiad read the gap as silence anyway: the first Nudge bought a wasted turn of status-polling, the second marched the count to its bound, and a healthy Run was six minutes from a false parking. The primary harm is that last step — parking a Run that needed no human defeats running unattended.

The indistinguishability was never a law, only a missing sentence. So the Protocol gains a third verb beside announcing and asking: `naiad wait "<what for>" [--seconds N]` — the agent declaring, before it ends its turn, that its silence is deliberate and what it is waiting on. A declared Wait suppresses the silence rule while it is in force. It is a new verb rather than a flag on `state`, because an Announcement means a phase is done and a Wait means the opposite; and not a Question, because a Question summons an answer typed into the session, which is precisely the interruption a Wait exists to prevent.

ADR 0006's second objection was that suppression without a re-poke stalls forever. The Wait answers it with a deadline: every Wait carries one — the agent's `--seconds`, or ten minutes by default — and expiry re-arms the ordinary silence rule, whose Nudge now names the expired Wait. Nothing new escalates; the one recovery shape is reused. For harness-tracked background work the deadline is only a backstop, because completion re-invokes the session. For external state — the review check on a pull request, which wakes nothing — the expiry Nudge *is* the scheduled re-check ADR 0006 said could not exist: the agent wakes, looks, and either announces or declares a fresh Wait. The blocking-wait pattern ADR 0006 prescribed is therefore superseded everywhere, and the `pull-request` Prompt rewritten: one waiting pattern, not two the agent must choose between.

Waits chain freely — each new one replaces the last and re-arms the Nudge count and the notification, exactly as a fresh Announcement does, because a re-declared Wait after a wake is the honest signal, not an evasion. What bounds a chain is a budget: thirty minutes of declared waiting per Announcement, the same order as the hang bound. A single Wait may claim up to whatever remains — `--seconds` beyond that is clamped rather than refused — and a Wait asked for past exhaustion is refused with an error telling the agent to announce or ask. The budget is charged for a Wait's lifetime — declaration until replacement or expiry, capped at its claim — rather than per declaration, because counting declarations would punish exactly the honest pattern the verb exists for: several background tasks finishing at different moments, each wake re-declaring for the remainder. The wake itself is invisible to Naiad (ADR 0002), so time spent working between a wake and the next declaration is charged as waited; the over-charge is accepted. Unbounded chaining fails the other way — each declaration is a signal, so the hang rule would never fire and a wait-looping agent would stall its Lane with no human ever told.

The agent learns the verb twice: a third rule in the Protocol preamble, and a sentence in the first Nudge's wording — the Nudge is the teachable moment, arriving precisely when an undeclared wait is being misread as silence.

## Consequences

The Protocol grows a verb, which is surface every agent acts against and the reason this is written down: narrowing or reshaping it later means retraining every Prompt and skill that learned it. Three numbers join the constants — the ten-minute default, the thirty-minute budget, and the clamp rule — and a new per-Run record carries the current Wait and the budget spent, re-armed per Announcement like Notices.

A lying or confused agent can now buy up to thirty minutes of unwatched stalling per Announcement by declaring waits for work that does not exist. Accepted: the old behaviour bought the same stall by simply not answering Nudges, and ended in the same place — the human told — only sooner and with more false alarms than real ones.

A Wait suppresses only the silence rule. The hang rule is untouched — a Wait is declared by ending a turn, and the hang rule watches sessions that never end one — and announcing supersedes any Wait outstanding, because the next Announcement re-arms the record as it does every other per-Announcement fact.

ADR 0006's three Prompt-authoring bounds (the ten-minute Bash cap, the terminal predicate, tolerating an absent input) stop being load-bearing for waiting, though the predicate and absent-input advice remain good Prompt hygiene where a State checks external results.
